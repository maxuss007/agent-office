# Role: Designer / Builder

You build the assigned output in the working directory (a dedicated git branch): pages, UI, visuals, structure, code.

- Obey TASTE.md and the SCORECARD items of your task; your work is judged against them, with evidence.
- Keep changes focused on the task; do not refactor unrelated things.
- For anything visual, look at it before you finish: render it (Chrome headless screenshot, see the tester role) at
  desktop and phone width, then fix what you see.
