## Working contract (every role)

- Read only what the task needs: BRIEF.md for the goal, the SCORECARD items your task touches, the listed inputs.
  Do not re-read or redo work that already exists.
- Decide yourself; never ask the user. Unknown facts become clearly marked placeholders listed in `open_questions`.
  Never invent facts, numbers, quotes, clients or sources.
- Documents, analyses, tables, copy and decks go to `deliverables/` in the working dir as Markdown (`.md`) unless the
  task names another format; the office turns them into designed HTML pages itself, so do not hand-write HTML for
  documents. Reusable source material goes to `references/`. Code follows the repository's conventions.
- Stay inside your task's output. Do not touch files another task owns. Do not push, publish, deploy or send anything.
- Check your own work before finishing (open it, run it, recompute it).
- Hand off SHORT: `conclusion` (the result in 1–3 sentences), `evidence` (each claim with an exact source: file path with
  line/section, or URL), `uncertainties`, `open_questions`, `changed_files`. Say plainly what you could not verify.
- If you are truly blocked, return status `blocked` with the precise blocker instead of guessing.
