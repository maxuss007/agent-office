---
name: agent-office-ui-polish-rules
description: Use when styling Agent Office buttons or hover effects.
category: ui-design
---

Follow these preferences the user set for Agent Office. They override generic styling defaults.

- Hover: scale only (about 1.025x) plus a slightly stronger border or shadow. Never change background or text colour on hover.
- Round every button, pill and input to the same radius as the step buttons.
- Do not repeat a status as a text label when the current step's icon already shows it.
- Put project controls (pause, stop, resume) at the end of the step row, in the same shape as the steps, coloured by step state.
- Keep secondary forms (for example a token entry) hidden until the user clicks the button that needs them.
- Agent name tags use the app's own colours, sit just above the character's head, and follow the light and dark theme.
- Show a dialog's back arrow only when it was opened from the flow that needs it.
- Dialog width target is 680 px; 520 px made descriptions wrap badly.
